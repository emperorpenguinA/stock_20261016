    スコアの仕組み

    次の順番でチャートを確認し、加点・減点した合計を 0〜100 のスコアにしています (50 が中立)。

    1. 月足・週足で大きなトレンドを確認: 高値・安値の更新 (直近の高値を上抜け = 上昇トレンド、直近の安値を下抜け = 下落トレンド) と中期線 (月足24ヶ月線・週足26週線) の向き。長期のトレンドが上向きなら短期の売買でも勝率が上がりやすい。
    2. 日足のローソク足
      • 2回以上同じ水準で反落した高値を抵抗線、反発した安値をサポートラインとし、その上抜け/割り込み
      • ボックス相場 (一定の高値と安値の間で上下) を上抜けたら買い、下限を割り込んだら売り
      • 安値切り上がり (押し目の安値が前回より高い) は上昇の強いサイン
      • 長い下ヒゲ (買い支え)・長い上ヒゲ (売り圧力)・大陽線/大陰線
    3. 移動平均線: 5日線が横ばい〜上向きの中でローソク足が5日線を上抜けたら買い時、横ばい〜下向きの中で下抜けたら売り時。移動平均線の並び (パーフェクトオーダー)、ゴールデン/デッドクロス、上昇トレンド中の25日線付近への押し目。
    4. 出来高: 出来高の多い陽線は上昇、多い陰線は下落の勢いを強める。直近2〜3ヶ月で出来高が最も積み上がった価格帯より株価が上なら上値が軽く、下なら「やれやれ売り」が出やすい。
    5. 補助指標: RSI・MACD・ボリンジャーバンドは参考程度の小さな重みで加味。

    移動平均線の期間は、日足 5・25・75日、週足 13・26・52週、月足 12・24・60ヶ月です。損切り目安は直近の安値と「終値 − 2×ATR」の近い方、利確目安は上にある抵抗線 (なければ「終値 + 3×ATR」) です。「投資スタイル」を変えると各カテゴリの重みが変わります。
