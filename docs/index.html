    手持ちのCSVで分析する

    一覧にない銘柄も、日足のCSV (列: Date, Open, High, Low, Close, Volume) を読み込めば同じ方法で分析できます。ファイルはブラウザ内だけで処理され、送信されません。

    スコアの仕組み

    各銘柄の直近の日足から次のシグナルを判定し、加点・減点した合計を 0〜100 のスコアにしています。50 が中立です。

    • トレンド: 株価と25日線の位置、25日線の向き、移動平均線の並び (5日・25日・75日)、ゴールデンクロス/デッドクロス、1年高値圏
    • モメンタム: MACD とシグナルの位置・交差、MACD のゼロライン
    • 反発/過熱: RSI の売られすぎ・買われすぎ、ボリンジャーバンド ±2σ
    • 出来高: 20日平均の1.5倍以上の出来高を伴う陽線/陰線

    「投資スタイル」を変えると各カテゴリの重みが変わります (順張りはトレンド重視、逆張りは反発シグナル重視)。損切り目安は終値 − 2×ATR、利確目安は終値 + 3×ATR です。
