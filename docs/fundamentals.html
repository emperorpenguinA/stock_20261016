# 監視 銘柄 スコア 4条件 成長 PER×PBR 将来

決算の推移 (年次)

評価の仕組み

年次の決算と株価指標から、次の項目を判定します。満たした項目の点数の合計を、判定できた項目だけで 0〜100 点に換算します。判定できない項目 (データなし) は点数に入れず「未確認」と表示します。

  • 銘柄選定の4条件: 上場2年目〜3年目 / 時価総額500億円以下 / オーナー創業社長 / 売上が伸びている
  • 成長株の基準: 売上高・営業利益・EPS が3期連続で前期比+10%以上、1株配当が3期連続で+2.5%以上
  • 決算書のチェック: 営業キャッシュフローとフリーキャッシュフローがプラスか。配当性向は参考表示 (成熟企業 40〜60%、成長企業 0〜30% が目安)
  • 割安かどうか: PER×PBR が15.5以下 (22.5未満は半分の点)。直近が減益の銘柄は割安とみなしません
  • 将来の株価: 来期のEPS × 今のPER。来期EPSはアナリスト予想、なければ過去のEPS成長率が続くと仮定します。上昇余地20%以上で満点、10%以上で半分
  • その他の指標: ROE 10%以上、PEG (PER÷EPS成長率) 1倍以下。自己資本比率・配当利回り・ネットキャッシュ比率は参考表示

有望 75以上 良好 55以上 普通 40以上 注意 40未満 (判定できた項目が半分未満なら「判定材料不足」)

データについて: 業績は Yahoo Finance から取得しています (最大4期分)。会社四季報の予想や会社の中期経営計画、四半期ごとの進捗率は含まれません。「オーナー創業社長」は自動で判定できないため、config/fundamentals_manual.json に書くと反映されます。気になる銘柄は、決算短信や四季報で数字を確かめてください。
