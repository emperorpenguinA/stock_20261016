# チャート銘柄ナビ

日本株・米国株のチャートを分析し、「いまチャートの形が良い銘柄」をスコア順に提案する静的Webページです。
月足・週足で大きなトレンドを確認したうえで、日足のローソク足・移動平均線・出来高から買い時/売り時を判定します。

- **今日の注目銘柄**: スコア上位 (「買い」以上) の3銘柄と、月足/週足/日足のトレンド、該当パターン (ボックス上抜け・安値切り上がり・押し目)
- **スコアランキング**: 全銘柄を 0〜100 点で順位付け (市場・検索で絞り込み)
- **詳細チャート (日足/週足/月足切替)**: ローソク足 + 移動平均線 + 出来高、RSI、MACD。高値・安値 (山と谷) のマーカー、抵抗線/サポートライン、ボックス、出来高の多い価格帯、損切り・利確の目安ライン
- **監視リスト**: ランキングや詳細の ☆ で銘柄を登録し、「監視リスト」タブで追加した順に確認できる。初動の銘柄は行頭に色が付く。リストはそのブラウザの localStorage に保存される (端末ごとに別のリスト)。一覧にない銘柄は `config/tickers.json` に追加すると、次の更新から取得される
- **5日線突破の初動**: 5日線を上抜けたばかりの銘柄に「初動」の印を付け、絞り込みもできる (毎日の監視リストチェックの最初の確認)
- **シナリオ**: 銘柄ごとに上昇シナリオ (どこを上抜けたら・利確目安) と下落シナリオ (損切りライン) を表示
- **決算の注意**: 次の決算発表まで14日以内の銘柄に印を付ける (決算をまたぐと株価が大きく動くことがあるため)
- **投資スタイル切り替え**: 標準 / 順張り / 逆張り でカテゴリの重みを変更
- **CSV分析**: 一覧にない銘柄も日足CSVを読み込めば同じ方法で分析 (週足・月足は日足から作成。ブラウザ内で処理)

> 本ページはテクニカル分析の参考用です。売買を推奨するものではなく、将来の値動きを保証しません。

## 業績 (ファンダメンタルズ) のページ

`fundamentals.html` では、年次の決算と株価指標から銘柄を評価します (ロジックは `docs/js/fundamentals.js`)。満たした項目の点数を、判定できた項目だけで 0〜100 点に換算します。

| 区分 | 項目 |
| --- | --- |
| 銘柄選定の4条件 | 上場2年目〜3年目 / 時価総額500億円以下 / オーナー創業社長 / 売上が伸びている |
| 成長株の基準 | 売上高・営業利益・EPS が3期連続+10%以上、1株配当が3期連続+2.5%以上 |
| 決算書のチェック | 営業CF・フリーCF がプラス、配当性向 (参考) |
| 割安かどうか | PER×PBR 15.5以下 (22.5未満は半分)。直近が減益なら対象外 |
| 将来の株価 | 来期EPS (アナリスト予想、なければ過去の成長率から) × 今のPER |
| その他 | ROE 10%以上、PEG 1倍以下、自己資本比率・配当利回り・ネットキャッシュ比率 (参考) |

業績データは `scripts/fetch_fundamentals.py` が Yahoo Finance から取得します (最大4期分)。「オーナー創業社長」は自動で判定できないため、`config/fundamentals_manual.json` に `"4058.T": {"ownerCeo": true, "note": "..."}` のように書くと反映されます。監視リストはチャートのページと共通です。

銘柄には `groups` で区分 (主要株 / 勉強リスト / 成長株) を付けており、両ページで絞り込めます。

## スコアの計算

ロジックは `docs/js/analysis.js` にあります。加点・減点の合計を 0〜100 (50が中立) に変換します。

| カテゴリ | シグナル |
| --- | --- |
| 月足・週足 | 高値・安値の更新によるトレンド判定、中期線 (24ヶ月線・26週線) の向き |
| ローソク足 (日足) | 直近の高値上抜け/安値割れ、抵抗線・サポートライン (2回以上反発した水準) のブレイク、ボックス相場の上抜け/下抜け、安値切り上がり/高値切り下がり、ヒゲ・大陽線/大陰線 |
| 移動平均線 | 5日線が横ばい〜上向きの中での上抜け (買い) / 横ばい〜下向きの中での下抜け (売り)、パーフェクトオーダー、ゴールデン/デッドクロス、上昇トレンド中の25日線への押し目 |
| 出来高 | 20日平均の1.5倍以上の出来高を伴う陽線/陰線、直近2〜3ヶ月の出来高が多い価格帯との位置関係 |
| 補助指標 | RSI(14)・MACD・ボリンジャーバンド (小さめの重み) |

移動平均線の期間: 日足 5/25/75日、週足 13/26/52週、月足 12/24/60ヶ月

月足・週足のどちらかが下落トレンドの銘柄は、日足に買いサインが出ても失敗しやすいため「様子見」(61点) までにとどめます。

上昇トレンドが続いているだけの「状態」は小さめに、ブレイクや安値切り上がりの確定直後といった「買い時のサイン」は大きめに加点します。加点が重なるほど伸びが緩やかになるので、100点に張り付きにくくなっています。

判定: 80以上「強い買い」/ 62以上「買い」/ 40以上「様子見」/ 25以上「売り」/ 25未満「強い売り」

## 公開方法 (GitHub Pages)

1. リポジトリの **Settings → Pages → Build and deployment → Source** を「GitHub Actions」にする
2. **Actions → 株価データ更新 → Run workflow** を実行する

Pages を有効にする前にワークフローが動くと、`deploy` ジョブが `Get Pages site failed ... Not Found` で失敗します (株価データの取得・コミットを行う `update` ジョブは影響を受けません)。上記 1 の設定後に再実行してください。

ワークフローは Yahoo Finance (yfinance) から日足 (1年)・週足 (5年)・月足 (10年) を取得して `docs/data/prices.json` をコミットし、`docs/` を Pages に公開します。平日は東証・米国市場の引け後に自動で更新されます。

初期状態の `prices.json` はデモ用の疑似データで、ページ上部に注意が表示されます。

## 銘柄の追加・変更

`config/tickers.json` を編集します。日本株は `7203.T` のように末尾に `.T` を付けます。

## ローカルで動かす

```sh
pip install -r requirements.txt
python scripts/fetch_data.py        # 株価を取得 (--demo で疑似データ)
python scripts/fetch_fundamentals.py  # 業績を取得 (--demo で疑似データ)
python -m http.server -d docs 8000  # http://localhost:8000 を開く
```

チャート描画には [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v4.2.0 (Apache-2.0) を `docs/vendor/` に同梱しています。
