# チャート銘柄ナビ

日本株・米国株の日足チャートをテクニカル分析し、「いまチャートの形が良い銘柄」をスコア順に提案する静的Webページです。

- **今日の注目銘柄**: スコア上位 (「買い」以上) の3銘柄と、その根拠
- **スコアランキング**: 全銘柄を 0〜100 点で順位付け (市場・検索で絞り込み)
- **詳細チャート**: ローソク足 + 移動平均線 (5/25/75日) + ボリンジャーバンド + 出来高、RSI、MACD。ゴールデン/デッドクロスのマーカー、ATR による損切り・利確の目安ライン
- **投資スタイル切り替え**: バランス / 順張り / 逆張り でシグナルの重みを変更
- **CSV分析**: 一覧にない銘柄も日足CSVを読み込めば同じ方法で分析 (ブラウザ内で処理)

> 本ページはテクニカル分析の参考用です。売買を推奨するものではなく、将来の値動きを保証しません。

## スコアの計算

直近の日足から次のシグナルを判定し、加点・減点の合計を 0〜100 (50が中立) に変換します。ロジックは `docs/js/analysis.js` にあります。

| カテゴリ | シグナル |
| --- | --- |
| トレンド | 25日線との位置・向き、移動平均線の並び (パーフェクトオーダー)、ゴールデン/デッドクロス、1年高値圏 |
| モメンタム | MACD とシグナルの交差・位置、MACD のゼロライン |
| 反発/過熱 | RSI(14) の売られすぎ/買われすぎ、ボリンジャーバンド ±2σ |
| 出来高 | 20日平均の1.5倍以上の出来高を伴う陽線/陰線 |

判定: 70以上「強い買い」/ 58以上「買い」/ 42以上「様子見」/ 30以上「売り」/ 30未満「強い売り」

## 公開方法 (GitHub Pages)

1. リポジトリの **Settings → Pages → Build and deployment → Source** を「GitHub Actions」にする
2. **Actions → 株価データ更新 → Run workflow** を実行する

ワークフローは Yahoo Finance (yfinance) から株価を取得して `docs/data/prices.json` をコミットし、`docs/` を Pages に公開します。平日は東証・米国市場の引け後に自動で更新されます。

初期状態の `prices.json` はデモ用の疑似データで、ページ上部に注意が表示されます。

## 銘柄の追加・変更

`config/tickers.json` を編集します。日本株は `7203.T` のように末尾に `.T` を付けます。

## ローカルで動かす

```sh
pip install -r requirements.txt
python scripts/fetch_data.py        # 実データを取得 (--demo で疑似データ)
python -m http.server -d docs 8000  # http://localhost:8000 を開く
```

チャート描画には [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v4.2.0 (Apache-2.0) を `docs/vendor/` に同梱しています。
